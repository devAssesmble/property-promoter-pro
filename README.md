One important CMNHousing feature

I would not make the customer manually design each Facebook/Instagram advertisement. The customer should enter the property once during onboarding, and CMNHousing should automatically reuse the photos, price, location, property type, amenities, description and contact/WhatsApp details to produce platform-specific mockups.

That makes the experience feel like a professional advertising platform, rather than a normal property-posting form.
